Know what you are measuring
Polygons return area in square metres; lines return length in metres. Points have no area or line length. Geometry coordinates are returned in WGS84 (longitude, latitude); calculations use a suitable local projected coordinate system, shown in each feature’s details. Invalid or unsupported features include a reason. Displayed values are rounded; the JSON export preserves the API values.
